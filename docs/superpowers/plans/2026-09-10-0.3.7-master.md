**Spec:** `docs/superpowers/specs/2026-09-10-0.3.7-design.md`

## Global Constraints

- Zero runtime dependencies; Node ≥ 20; ESM only.
- `hooks/omelette-guard.mjs` imports nothing from `core/`; no literal `{{` outside the render placeholders (`{{marker}}`, `{{handoff}}`); silent + exit 0 on anything malformed; exit 2 only for the PreToolUse refusal.
- The CLI never writes Claude Code's settings files; it prints snippets.
- No `--dangerously-*` flags; env allowlist and billing-key scrub untouched; `units/gemini/models.js` never edited here.
- Public repo: no personal data, no absolute home paths in committed files (`<repo root>` in plans and docs).
- Every behaviour change gets a test; `npm test` pristine before each commit; no test spawns a real vendor binary; never `doctor --probe-sandbox` against the real fleet home.
- Coder sub-agents never commit — plans end tasks with "Report to the orchestrator"; the session commits per task (atomic commits).
- Constants, verbatim: short contract line `omelette-fleet: read-only unit; the operating model is in .claude/rules/omelette-fleet.md — the units propose, you apply.`; `contract: auto | full | short` default `auto`; `handoff.compactSummary` boolean default `true`; block heading `## Compaction summary <ISO> (trigger: manual|auto)`, body bounded to 8 KiB; `workflow.merge: session | pr` default `session`; usage header `usage: input=<n> output=<n> [cachedInput=<n>] [reasoning=<n>]`; `results --stats [unit] [--since <ISO date | 24h | 7d>]`; empty spool prints `no results`.
- Linux before the tag: the suite runs on Linux (Docker, or the pushed branch's CI matrix) before merging.

## Shared interfaces

- `core/rules.mjs`: `export function contractFor({ cwd, env, mode })` → `{ text, short: boolean, reason: 'rules installed here' | 'rules installed globally' | 'no rules file in <cwd>' | 'contract=full' | 'contract=short' }`; `unitInstructions(unit, { cwd, env, mode })` uses it. The rules marker test is `parseRulesMarker` (exists). (P1; P4 must not change the marker format.)
- `core/config.mjs`: `SETTINGS_SCHEMA.contract = { type: 'enum', values: ['auto','full','short'], default: 'auto' }` (P1); `HANDOFF_SCHEMA.compactSummary = { type: 'boolean', default: true }` (P3); `WORKFLOW_SCHEMA = { merge: { type: 'enum', values: ['session','pr'], default: 'session' } }` + `workflowSettings(env)` (P4). `fleetSettings` returns `contract`.
- `core/results.mjs`: `HEADER_KEYS` gains `'usage'` after `'effort'`; `renderResult` writes it only when `r.usage` is an object with numeric fields; `parseResult` returns `usage: { input, output, cachedInput?, reasoning? } | null`. (P2) `onResult({...})` from `finish()` carries `usage` (the same object the status feed gets). (P2)
- `hooks/omelette-guard.mjs`: dispatch gains `postCompact(event)`; reuses `readBounded`, `ledgerDir`, `ledgerNames`, the PreCompact append path; `AUTO_HANDOFF.compactSummary` read from the rendered literal. (P3) `HOOK_EVENTS = ['PreToolUse','PreCompact','SessionStart','PostToolUse','Stop','PostCompact']`. (P3)
- `core/rules.mjs` `renderRulesFile(version, { merge })` fills `{{merge}}`; `KINDS.rules.render` passes `workflowSettings().merge`. (P4)
- `bin/omelette-fleet.mjs`: doctor's per-project block prints, in this order after `handoff`: `contract` (P1), `merge policy` (P4). `cmdResults` gains `--stats` (P2).
