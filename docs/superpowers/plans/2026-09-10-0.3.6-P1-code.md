# 0.3.6 · P1 — the code: research `cwd`, a probe deadline that ends the child, Codex's cap, a cancel that keeps the error, image tools that answer with a path

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use `- [ ]`. **Coder sub-agents never commit** — the last step of every task is a report to the orchestrating session, which reviews and commits on `feat/0.3.6`.

**Goal:** The five code items of the 0.3.6 backlog, in the spec's order. `grok_research`, `gemini_research` and `codex_research` take an optional absolute `cwd`, so `doctor --probe-sandbox` stops changing this process's directory to get a run into its throwaway one (S1). The probe's deadline ENDS the vendor run instead of walking away from it, through an `AbortController` and a runtime built with `cancel: 'kill'` (S3). Codex's built-in `outputCap` becomes `CODEX_OUTPUT_CAP = 4000000` (S2). A cancelled Grok run keeps the error Grok had already reported (S4). All four image tools answer with a bare path or an error, never a path with a marker on it (S5). Then the docs that describe each of those, and the `## 0.3.6 — unreleased` CHANGELOG heading P2 appends to.

**Architecture:** Adapter and doctor work on existing flows. Each of the three adapters grows one `checkCwd`-validated input on its research tool and one internal runner that keeps the process result beside the interpreted answer (the image tools need `killed` / `capped` / `cancelled`, which live on the spawn result and not on the text). `core/artifact.mjs` grows the one sentence all four image tools say when there is no artifact. `core/unit.mjs` grows a single runtime option, `cancel`, documented as internal to doctor. `bin/omelette-fleet.mjs`'s `probeUnit` loses `process.chdir` and its `finally`, `probeRuntimeEnv` loses its path absolutising, and the deadline gains an abort. Nothing else in `core/` moves.

**Tech Stack:** Node ≥ 20, zero runtime dependencies (`node:` builtins only), plain ESM, `node --test test/` with fake vendor binaries under `test/`.

**Spec:** `docs/superpowers/specs/2026-09-10-0.3.6-design.md` — **S1, S2, S3, S4 and S5 are this package, in full.** S6–S9 (the rules and ORCHESTRATION text) belong to P2 and are not touched here.

**Master plan:** `docs/superpowers/plans/2026-09-10-0.3.6-master.md`. Its "Shared interfaces" are binding, verbatim:

   * Why an image run has no artifact to hand back, when the run's OWN bounds
