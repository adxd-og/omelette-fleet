# 0.3.5 Implementation Plan — master

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The guard and `doctor` infer a 1M ceiling from a `[1m]` model suffix; `doctor --probe-sandbox` proves each unit's sandbox on a throwaway directory; Grok's cap fits a long review; a deep-research result is filed under its stage models; an unreadable settings file is named whichever reader hit it.

**Architecture:** §1 and §5 extend the settings readers on both sides — `contextCeiling` in the self-contained guard and `readClientSetting`/`resolveContextWindow` in the CLI — with one more source and an `unreadable` list; the two must agree source for source. §3 and §4 are unit-local (Grok's built-in cap; Gemini's deep-research `ctx.usedModel` report). §2 adds an opt-in probe to `cmdDoctor` that drives a unit through the same in-process `createUnitRuntime`/`callTool` path `cmdCall` uses, against a fresh private temp directory, and reads the verdict off the filesystem.

**Tech Stack:** Node ≥ 20, zero runtime dependencies, `node --test test/` with fake vendor binaries, plain ESM.

**Spec:** `docs/superpowers/specs/2026-09-09-0.3.5-design.md`

## Global Constraints

- Zero runtime dependencies; Node ≥ 20; ESM only.
- `hooks/omelette-guard.mjs` imports nothing from `core/`; no literal `{{` outside the two render placeholders; silent + exit 0 on anything malformed; exit 2 only for the PreToolUse refusal.
- The CLI never writes Claude Code's settings files; it prints snippets.
- No `--dangerously-*` flags; env allowlist and billing-key scrub untouched.
- Public repo: no personal data, no absolute home paths in committed files (`<repo root>` in plans and docs).
- Every behaviour change gets a test; `npm test` pristine before each package commit; no test spawns a real vendor binary.
- Coder sub-agents never commit — plans end tasks with "Report to the orchestrator", never `git commit`.
- Ceiling precedence, verbatim: `handoff.contextWindow` → `CLAUDE_CODE_AUTO_COMPACT_WINDOW` → `autoCompactWindow` → `model[1m]` → 200000. Source names, verbatim: `handoff.contextWindow`, `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, `autoCompactWindow`, `model[1m]`, `default`.
- Probe is opt-in (`--probe-sandbox`); verdict from the filesystem only; only `BREACHED` changes doctor's exit code; the probe directory lives under `os.tmpdir()`, mode 0700, removed in every path.
- Grok built-in `outputCap` 10000000; fleet default 400000 unchanged.
- `settings:` line wording, verbatim: `settings: <path> unreadable — its values were not consulted`.

## Shared interfaces

- Guard `contextCeiling(env)` returns `{ window, source }` with `source` one of the five names above; a new helper `modelWindow(env)` → `{ window: 1000000, source: 'model[1m]' } | null` reads `ANTHROPIC_MODEL` then the user-scope settings pair's `model` key (same `readBounded(..., { follow: true })` rules as `autoCompactWindow`). (P1)
- CLI `readClientSetting(name, { global, cwd, env, accept })` → `{ value, source, unreadable: string[] }`; `resolveContextWindow(contextWindow, { cwd, env })` → `{ window, source, unreadable: string[] }`; `handoffReport` passes `unreadable` up; `cmdDoctor` merges via the existing `mergeUnreadable`. (P1)
- `ctx.usedModel(id)` exists since 0.3.4 on the spawn ctx (idempotent, first non-empty string wins). (P2 uses it.)
- `cmdDoctor(argv)` gains flag parsing for `--probe-sandbox`; `probeUnit(unit, { cfg, env, log })` → `{ verdict: 'held'|'BREACHED'|'skipped', reason, seconds, reply, path }`; the per-unit block prints `sandbox: …` last. (P3)
