## P2 — rules and docs (S6–S9), the brief

Edit `rules/omelette-fleet.md` (the template; the rendered `.claude/rules/…` copy is regenerated, never edited) and mirror every sentence in `docs/ORCHESTRATION.md`'s corresponding section:

1. Under "Operating model for the session", after the "Give each delegate one job…" bullet, add two bullets:
   - **When a delegate is justified — all four, or the session does it itself.** The subtask is independent (its own files or its own question); it resolves a **named uncertainty** ("does the migration run on 0.3.2 data?", not "look at the architecture"); a wrong answer would cost something material; the expected output fits one sentence.
   - **The small-change exception.** The session edits directly when the change is at most **20 lines**, changes no behaviour beyond the fix, carries its test in the same commit (or touches only docs and comments), and gets a ledger line. The tester still runs on every coder result; a docs-only edit needs none.
2. New section "## Reviews" between "Tester flow" and "Spawning sub-agents":
   - **A finding has four parts, or it is a question.** Every review brief asks for, and every finding is recorded as, `location · scenario · consequence · how to confirm`. The orchestrator rules on each: `verified`, `rejected (reason)` or `needs-check (what)`, in the ledger.
   - **First review clean, re-review continued.** The first review of a change runs with a clean context — no coder summary, no earlier findings. A re-review after a fix round is briefed with the previous findings and the rulings on them, so it verifies the fixes instead of rediscovering the file.
3. Under "Ledger and handoff", a bullet: **Close a plan with its review yield**: one line `review yield: <findings> found / <accepted> accepted / <rejected> rejected — <the two or three that mattered>`. It is the cheap measure of what the reviews were worth; keep it honest.
4. `test/rules.test.mjs`: one test that the rendered rules file contains the three headings/phrases: `When a delegate is justified`, `## Reviews`, `review yield:`.
5. CHANGELOG bullet under `## 0.3.6`: "The rules say when, not only who…" (one bullet covering S6–S9).
6. Do NOT write the archived ledgers' review-yield lines (the session does; `.omelette/` is gitignored).
