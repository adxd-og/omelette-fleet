# 0.3.4 Implementation Plan — master

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The guard makes the session write its `## Handoff` before the context is compacted away (nudge at 90 %, one held `Stop`), contains the tester like the coder, and closes three one-line backlog items.

**Architecture:** Everything in §1 lives in the self-contained hook script `hooks/omelette-guard.mjs` (rendered into projects by `core/rules.mjs`), reads the session transcript's tail for the last request's token usage, keeps per-session state in `.omelette/handoff-state.json`, and speaks to Claude Code through the documented `PostToolUse` `additionalContext` and `Stop` `decision: block` outputs. Config (`handoff.*`) is validated in `core/config.mjs` and substituted into the script at render time through a `{{handoff}}` placeholder. `doctor` learns two more hook events and one line. §2 hardens the same script's git classifier; §3 touches `core/unit.mjs` (spool `model:`), `bin/omelette-fleet.mjs` (`readClientEnv`) and `docs/CONFIG.md`.

**Tech Stack:** Node ≥ 20, zero runtime dependencies, `node --test test/` (fake vendor binaries in `test/`), plain ESM.

**Spec:** `docs/superpowers/specs/2026-09-08-0.3.4-design.md`

## Global Constraints

- Zero runtime dependencies; Node ≥ 20; ESM only.
- `hooks/omelette-guard.mjs` imports nothing from `core/` — it is copied into other projects as one file. Configuration reaches it only through render-time placeholders (`{{marker}}`, new `{{handoff}}`).
- The guard never fails somebody's turn on a guess: any unreadable/malformed input → silent, exit 0, no output. Exit 2 stays reserved for the git refusal.
- The CLI never writes Claude Code's `settings.json` / `.claude.json` / `.mcp.json`; it prints snippets.
- No `--dangerously-*` flags; env allowlist and billing-key scrub untouched.
- Public repo: no personal data, no absolute home paths in committed files (write `<repo root>` in plans and docs).
- Every behaviour change gets a test; `npm test` pristine before each package is committed.
- Coder sub-agents never commit: the orchestrating session commits each reviewed task. Plans end tasks with "report to the orchestrator", not with `git commit`.
- Threshold default **90**; `handoff.threshold` bounds 50–99; `contextWindow` 0 = resolve at run time; default ceiling **200000**.
- Hook output is exactly one JSON object on stdout when there is something to say, nothing otherwise.
- `.claude/` and `CLAUDE.md` are gitignored: re-render managed copies with `node bin/omelette-fleet.mjs rules --agents --hooks` after changing a template, never commit them.

## Shared interfaces (so the three plans agree)

- `core/config.mjs`: `export const HANDOFF_SCHEMA = { enabled: {type:'boolean', default:true}, threshold: {type:'posint', min:50, max:99, default:90}, contextWindow: {type:'nonneg', default:0} }` and `export function handoffSettings(env = process.env) → { enabled, threshold, contextWindow, warnings }` (P1). Whatever coercion type names exist in `coerce` are reused; if `min`/`max` or a non-negative integer type do not exist, P1 adds them.
- `core/rules.mjs`: `HOOK_EVENTS = ['PreToolUse', 'PreCompact', 'SessionStart', 'PostToolUse', 'Stop']`; `renderHookFile(name, version, handoff)` fills `{{handoff}}` with `JSON.stringify({ enabled, threshold, contextWindow })`; `hookSettingsSnippet` emits five groups (P1). P2 does not change the snippet.
- `hooks/omelette-guard.mjs`: dispatch gains `postToolUse(event)` and `stop(event)`; `preCompact` also resets the session's state entry (P1). `GUARDED_AGENTS = new Set(['omelette-coder', 'omelette-tester'])` replaces `GUARDED_AGENT` (P2). Both packages keep `say(stream, text)`, `ledgerDir(event)`, `readEvent()` as they are.
- `bin/omelette-fleet.mjs`: `readClientEnv(name, opts) → { value, source, unreadable: string[] }` (P3; P1 reads `autoCompactWindow` from the settings files through the same helper family and must tolerate the added field). Doctor prints the `handoff:` line (P1) and the `settings: <path> unreadable` line (P3) in the per-project block, handoff line first.
- `core/unit.mjs`: tool ctx gains `usedModel(id)`; `finish()` spools `model:` = explicit/configured model → `usedModel` report → `'(vendor default)'` (P3).
