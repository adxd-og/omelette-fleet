# 0.3.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`.

**Goal:** Turn three 0.3.0 rules into mechanisms (ledger/handoff hook, mechanical tester handoff, coder guard), make agent settings configurable and dynamically adjustable, and make Grok's hard-kill salvage actually work.

**Architecture:** `core/rules.mjs` grows a registry of managed-file KINDS (rules, agents, skills, hooks) with one marker builder per kind; `bin/omelette-fleet.mjs` `rules` gains `--hooks` (and `--agents` also writes the skill), `doctor`/`update` report all kinds. `core/config.mjs` gains a validated top-level `agents` block that templates render from. `units/grok/adapter.mjs` switches research/review to `streaming-messages-json` with one parser for finished and killed runs.

**Spec:** `docs/superpowers/specs/2026-09-06-0.3.1-design.md` (read it; the spike facts there are binding).

## Global Constraints
- Branch `feat/0.3.1`. Coder sub-agents never commit; the orchestrator commits each task after its review.
- Zero runtime dependencies. The CLI never shells out. Claude Code's `.claude.json` / `settings.json` are READ, never written.
- Ownership = the marker, exact line, one builder per kind (`core/rules.mjs` `markerPattern`). A file without its marker is never overwritten (except `--force`) and never removed.
- Tests never touch the network or need a vendor CLI; CLI tests spawn the bin with a throwaway HOME/OMELETTE_HOME and `OMELETTE_UPDATE_CHECK=0`, and pass `cwd`.
- Existing 177 tests stay green; `npm test` pristine.
- Version → 0.3.1 in Task 6.

### Task 1: Grok streaming output and one parser

**Files:** Modify `units/grok/adapter.mjs` (`buildArgs`, `interpretGrok`, `grokAnswer`), `test/grok.test.mjs`; docs touched in T5.

**Interfaces:** `buildArgs({...})` emits `'--output-format', 'streaming-messages-json', '--include-partial-messages'` when `isResearchToolset(tools)`; image tools keep `plain`. `interpretGrok(res, { jsonMode, timeoutS })` returns `string | { text, usage?, partial? }` exactly as today; `parseStream(stdout) → { text, stopReason, usage, finalText }` is the single parser: NDJSON lines; `stream_event` with `event.type === 'content_block_delta'` and `event.delta.type === 'text_delta'` append to `text` (ignore `thinking_delta`); a whole message line with `type: 'assistant'` (Anthropic wire format: `message.content[]` text blocks) sets `finalText`; `message_delta` / final message provide `stop_reason` and `usage` (`input_tokens`, `output_tokens` → status feed `usage: { input, output }`); malformed lines are skipped. Answer = `finalText || text`.

Verified fixture shape (from the 2026-09-06 probe): line 1 `{"type":"system","subtype":"init",...}`; then `{"type":"stream_event","event":{"type":"content_block_delta","index":1,"delta":{"type":"text_delta","text":"1"}},...}` ×N; `content_block_start/stop`, `message_start`; whole messages after. Build fixtures from that shape; where the final-message shape is uncertain, accept both `{"type":"assistant","message":{...}}` and a top-level `{"type":"message",...}` and say so in a comment.

- [ ] Step 1: tests — (i) `buildArgs` research → streaming flags, image → plain; (ii) `parseStream` on a complete fixture (deltas + final message; final wins when it differs); (iii) killed mid-delta fixture (`killed: true`, no final message) → text assembled + hard-kill marker + `partial: true`; (iv) tool-use blocks between text blocks → only text blocks assembled; (v) empty stdout + killed → throws; (vi) `stop_reason` other than `end_turn` → early-stop marker; (vii) usage propagated.
- [ ] Step 2: run, watch fail. Step 3: implement. Step 4: `npm test`.
- [ ] Step 5: fake-binary CLI test in `test/cli.test.mjs` if the existing grok fake emits `json` — update the fake to emit streaming NDJSON for research calls.

**Interfaces:** `AGENT_SETTINGS_SCHEMA = { coder: { model: {type:'string', default:'opus'}, effort: {type:'enum', values:['low','medium','high','xhigh','max'], default:'xhigh'} }, tester: { model: {default:'sonnet'}, effort: {default:'xhigh'}, maxTurns: {type:'posint', default: 80} } }`; `agentSettings({ env }) → { coder:{model,effort}, tester:{model,effort,maxTurns}, warnings }` (invalid → default + warning, like `fleetSettings`). Templates: `model: {{model}}`, `effort: {{effort}}`, tester adds `maxTurns: {{maxTurns}}`; `renderAgentFile(name, version, settings = agentSettings())` substitutes all placeholders; a leftover `{{` is a test failure. `set agents.tester.maxTurns=120` writes `{ agents: { tester: { maxTurns: 120 } } }` merged into the file; `show agents` prints the block with sources (default / file). `rules --agents` output for a changed value: `written … (v0.3.1, was 0.3.1)` (content differs → rewrite).

### Task 3: Managed kinds registry + the `/omelette-test` skill

**Files:** Create `skills/omelette-test/SKILL.md`; modify `core/rules.mjs` (KINDS registry), `bin/omelette-fleet.mjs` (`managedFiles` uses the registry; `--agents` also writes the skill under `.claude/skills/omelette-test/SKILL.md`; `--remove --agents` removes it; doctor `agents` line counts it as `(3)` or shows a separate `skills` line — choose one and be consistent: separate `skills` line), tests.

**Skill template (exact):**
```
---
# omelette-fleet skill v{{version}} · managed by `omelette-fleet rules --agents` · edits are overwritten on refresh
name: omelette-test
description: Clean-context tester handoff — forks omelette-tester with the approved spec and the diff taken from git at invocation, so the tester never receives the coder's summary. Usage: /omelette-test <spec path>
context: fork
agent: omelette-tester
disable-model-invocation: true
argument-hint: [spec path]
---
Spec to test against: read `$ARGUMENTS` first; it is the authority.

Diff of the working tree, taken from git at invocation (uncommitted work included):
!`git diff HEAD`

Untracked files (read them by path if they are part of the change):
!`git ls-files --others --exclude-standard`

Now follow your procedure: list the behaviours the spec promises, check coverage, write additional tests in a NEW file, run them through the real runner, quote the raw output, and rule each failure test-vs-spec. Never edit the implementation or the implementer's tests.
```
Marker: line 2 YAML comment, same builder shape as agents (`SKILL_MARKER(version)`), parser `parseSkillMarker`. Note the `!`…`` lines must survive rendering verbatim (no placeholder processing beyond `{{marker}}`).

### Task 4: Hooks kind — `rules --hooks`, the guard script, doctor wiring check

**Files:** Create `hooks/omelette-guard.mjs` (template); modify `core/rules.mjs` (kind `hooks`, `//` marker on line 1, `parseHookMarker`), `bin/omelette-fleet.mjs` (`rules --hooks`, `--remove --hooks`, `--print --hooks`; prints the settings snippet after a write; `doctor` `hooks` line with wiring state read from `.claude/settings.json` (project) / `$CLAUDE_CONFIG_DIR|~/.claude/settings.json` (global) — READ ONLY; `update` hint), tests.

**Guard script (exact behaviour):** `// omelette-fleet hook v{{version}} · managed by \`omelette-fleet rules --hooks\` · edits are overwritten on refresh` on line 1. Reads stdin JSON (never throws: malformed → exit 0). `hook_event_name === 'PreToolUse'`: if `agent_type === 'omelette-coder'` and `tool_name === 'Bash'` and `/\bgit\s+(commit|push|stash|checkout\s+-b|switch\s+-c|worktree)\b/.test(tool_input.command)` → stderr `omelette-coder never commits, pushes, stashes, branches or opens worktrees; report instead` and exit 2; else exit 0. `hook_event_name === 'PreCompact'`: for every `.omelette/ledger-*.md` under `cwd` (from stdin `cwd`, else process.cwd()), append `\n## Compaction <ISO> (trigger: <trigger>) — re-read this ledger before continuing\n`; print `HANDOFF: re-read .omelette/ledger-*.md before continuing.` to stdout; exit 0. Unknown event → exit 0. Zero deps, Node >= 20 ESM.

**Settings snippet printed after a write** (exact JSON, paths absolute to the written script):
```
{ "hooks": {
  "PreToolUse": [ { "matcher": "Bash", "hooks": [ { "type": "command", "command": "node <abs path>/omelette-guard.mjs" } ] } ],
  "PreCompact": [ { "hooks": [ { "type": "command", "command": "node <abs path>/omelette-guard.mjs" } ] } ] } }
```
Doctor wiring check: settings.json parsed; `wired` = both events reference the script path (string contains `omelette-guard.mjs`); states `absent` / `foreign` / `v0.3.1 (wired: PreToolUse, PreCompact)` / `v0.3.1 (NOT wired — paste the snippet from rules --hooks)`.

- [ ] Tests: guard script driven directly with stdin fixtures (coder+commit → exit 2 + message; coder+`git status` → 0; main thread+commit → 0; PreCompact appends to two ledgers and prints HANDOFF; malformed stdin → 0); `rules --hooks` writes the script, prints the snippet containing the absolute path, idempotent, foreign refused, `--remove --hooks`; doctor wiring states with a fixture settings.json; `--dry-run --hooks` writes nothing.
- [ ] Implement; `npm test`.
