# 1.7.3 — Ledger lifecycle and the decisions register: implementation plan

**Goal.** A ledger names its branch and closes when the branch is gone; `omelette-fleet ledger sweep` moves the binding rulings of a closed ledger into a decisions register and the ledger into `.omelette/archive/`; the guard runs that sweep on every session start and, after a compaction or a `/clear`, prints the open ledger's last handoff, the register and the backlog's first table, in that order.

**Architecture.** One new module, `core/ledger.mjs`, holds every rule of the lifecycle: header parsing, classification through `git show-ref`, the register path and its `register:` redirect, the harvest of `Ruling(binding):` lines, the sweep, `ledger open`. The CLI (`ledger open`, `ledger sweep`, `doctor`) imports it statically. The guard template stays standalone for what it refuses and prints, and loads the module with one `await import()` from the package root rendered into it (`{{package}}`), inside try/catch: a failed import is one stderr line, the sweep is skipped, the stamp and the print still happen. The print code is the guard's own; the order of its ledgers and the register path it reads come from the sweep's result.

**Tech stack.** Node ≥ 20, ESM, zero runtime dependencies, `node --test`. Git through `spawnSync`, no shell, in the environment `core/check.mjs`'s `gitChildEnv` builds.

**Spec.** `docs/superpowers/specs/2026-11-02-1.7.3-ledger-lifecycle-design.md` (approved 2026-11-02, commit 56f1b3f).

## Global constraints

- **Binding interfaces (the spec's; other work is planned against them).** `core/ledger.mjs` exports `classifyLedger`, `readRegisterPath` and `sweepLedgers(projectDir, opts)`. The hook template carries `{{package}}`. The ledger header is `branch: <name>`. The binding mark is `Ruling(binding):`. The register is `.omelette/decisions.md`; its optional first line `register: <relative path>` redirects. Register lines: ``- <path>:<line> · `<fragment>` · <YYYY-MM-DD> · <plan> · <ruling>`` with a pointer, `- <YYYY-MM-DD> · <plan> · <ruling>` without; `<ruling>` runs from `Ruling(binding):` to the end of the ledger line, a trailing pointer moved to the front.
- **No new key in `fleet.config.json`.** `handoff.enabled=false` switches the guard's sweep off with its stamp and print; `ledger sweep` and `doctor` still sweep.
- **The guard stays standalone** for what it refuses and prints. Its static imports stay `node:*`. Its one dynamic import is `core/ledger.mjs` from `PACKAGE_ROOT`, inside try/catch. Any failure in the ledger path is at most one stderr line and exit 0. `PreToolUse` never touches the import.
- **1.7.2's write discipline** (CHANGELOG "## 1.7.2"):
  - the register is written through a tmp file opened `wx` under an unpredictable name (`<target>.<pid>.<12 hex>.tmp`) and renamed over the target;
  - a ledger append is `O_WRONLY | O_APPEND | O_NOFOLLOW | O_NONBLOCK` on a file that fstats as regular with `nlink === 1`;
  - every read is `lstat` + `O_NOFOLLOW | O_NONBLOCK` + `fstat` on the fd (`readBoundedFile`);
  - a move never overwrites: `linkSync` + `unlinkSync`.
- **The git child:** `spawnSync('git', ['--no-optional-locks', 'show-ref', '--verify', '--quiet', 'refs/heads/<branch>'], { cwd: projectDir, env: gitChildEnv(env), timeout: timeoutMs, killSignal: 'SIGKILL', stdio: ['ignore', 'ignore', 'pipe'], encoding: 'utf8', windowsHide: true })`, `timeoutMs` 2000 by default. `ledger open` alone also runs `git --no-optional-locks symbolic-ref --quiet --short HEAD` the same way. /**
```js
 * omelette-fleet :: test/fixtures/ledger-1.7.3.mjs
 * A throwaway project for the 1.7.3 ledger tests: a real git repository on
 * `main` with one empty commit (or none, with `git: false`), an `.omelette/`
 * beside it, and the helpers the tests share. Never this checkout.
 */
import { spawnSync } from 'node:child_process';
import { lstatSync, mkdirSync, mkdtempSync, readFileSync, readdirSync, readlinkSync, realpathSync, writeFileSync } from 'node:fs';
import { devNull, tmpdir } from 'node:os';
import { dirname, join } from 'node:path';

const HAS_GIT = spawnSync('git', ['--version'], { encoding: 'utf8' }).status === 0;
export const GIT_SKIP = HAS_GIT ? false : 'git is not on PATH — these tests need a real repository';
const GIT_ID = ['-c', 'user.name=omelette test', '-c', 'user.email=test@example.invalid', '-c', 'commit.gpgsign=false'];

/** A ledger with the 1.7.3 header, then `lines`, ending in a newline. */
export const ledger = (branch, ...lines) => ['# ledger', `branch: ${branch}`, '', ...lines, ''].join('\n');

export function project({ git = true } = {}) {
  const dir = realpathSync(mkdtempSync(join(tmpdir(), 'omelette-ledger-')));
  mkdirSync(join(dir, '.omelette'));
  const run = (args) => {
    const r = spawnSync('git', [...GIT_ID, ...args], {
      cwd: dir, encoding: 'utf8',
      env: { PATH: process.env.PATH, HOME: dir, GIT_CONFIG_NOSYSTEM: '1', GIT_CONFIG_GLOBAL: devNull },
    });
    if (r.status !== 0) throw new Error(`git ${args.join(' ')}: ${r.stderr}`);
    return (r.stdout || '').trim();
  };
  if (git) {
    run(['init', '-q']);
    run(['symbolic-ref', 'HEAD', 'refs/heads/main']);
    run(['commit', '-q', '--allow-empty', '-m', 'init']);
  }
  const write = (rel, text) => {
    const p = join(dir, rel);
    mkdirSync(dirname(p), { recursive: true });
    writeFileSync(p, text);
    return p;
  };
  const read = (rel) => readFileSync(join(dir, rel), 'utf8');
  /** Every path under the project but `.git`: a file's text, `dir`, or `symlink → <target>`. */
  const snapshot = () => {
    const out = {};
    const walk = (rel) => {
      for (const name of readdirSync(rel ? join(dir, rel) : dir).sort()) {
        if (!rel && name === '.git') continue;
        const r = rel ? `${rel}/${name}` : name;
        const st = lstatSync(join(dir, r));
        if (st.isSymbolicLink()) out[r] = `symlink → ${readlinkSync(join(dir, r))}`;
        else if (st.isDirectory()) { out[`${r}/`] = 'dir'; walk(r); }
        else out[r] = readFileSync(join(dir, r), 'utf8');
      }
    };
    walk('');
    return out;
  };
  return { dir, git: run, write, read, snapshot };
}
```

- [ ] **Step 3: implement `core/ledger.mjs`** (file header comment: what the module is, who imports it — the CLI statically, the guard dynamically — and that it writes only under `.omelette/` and to the register).

**Imports.** `spawnSync` (node:child_process); `closeSync`, `constants`, `lstatSync`, `mkdirSync`, `openSync`, `readdirSync`, `writeSync` (node:fs); `join` (node:path); `gitChildEnv`, `readBoundedFile` (./check.mjs); `visible` (./log.mjs). Task 3 and Task 4 add to these.

**Header rule.**
- `const HEADER = /^branch:[ \t]*(\S+)[ \t]*$/`.
- `const BRANCH = /^(?!-)(?!.*\.\.)(?!.*\/\/)(?!.*\.lock$)[A-Za-z0-9._\/-]+(?<![\/.])$/`.

**`parseLedgerHeader(text)`.**
- Split on `/\r?\n/` and look at the first `HEADER_LINES` lines.
- The FIRST line starting with `branch:` decides: its `HEADER` capture when that also passes `BRANCH`, otherwise `null`.
- No such line: `null`.

**`branchExists(projectDir, branch, opts)`.** The `spawnSync` call of Global constraints, mapped:

| `spawnSync` result | Returns |
|---|---|
| `r.error.code === 'ENOENT'` | `{ error: 'no-git' }` |
| `r.error.code === 'ETIMEDOUT'` or `r.signal === 'SIGKILL'` | `{ error: 'timeout' }` |
| status 0 | `{ exists: true }` |
| status 1 | `{ exists: false }` |
| stderr matches `/not a git repository/i` | `{ error: 'not-a-repo' }` |
| anything else | `{ error: 'git-failed' }` |

**`classifyLedger(projectDir, name, opts)`.**
- `null` when `name` does not match `LEDGER_FILE`, or the path does not lstat as a regular file.
- Otherwise the text is `readBoundedFile(join(projectDir, '.omelette', name), HEADER_READ_BYTES)`, and `plan` is the `LEDGER_FILE` capture.
- No header: `{ name, plan, state: 'untracked' }`.
- `branch === 'main'`: `{ name, plan, state: 'standing', branch }`, with no git call.
- Otherwise `branchExists` decides: `open` or `closed` with `branch`; on an error, `{ name, plan, state: 'unknown', branch, error }`.
- A key that does not apply is absent, never `undefined`: the tests compare with `deepEqual`.

**`listLedgers(projectDir, opts)`.** `dir = join(projectDir, '.omelette')`.
- `lstat` ENOENT: `{ ledgers: [], archived: 0, error: null, absent: true }`.
- Not a directory, or a symlink: `{ ledgers: [], archived: 0, error: 'not-a-directory' }`.
- Otherwise the names matching `LEDGER_FILE`, sorted, each classified (a `null` is skipped).
- After the first git error, every later named branch is `unknown` with that same error, and git is not called again. `error` is that first error code, or `null`.
- `archived` counts `LEDGER_FILE` names in `.omelette/archive/` when that lstats as a real directory, else 0. The names are read; the contents never are.

**`openLedger(projectDir, plan, opts)`.** Checks, in this order, each an `{ error }` with the exact text below:

| Check | Error text |
|---|---|
| `plan` fails `PLAN_NAME` | `plan name "${visible(plan)}" must start with a letter or digit and hold only letters, digits, ".", "_" or "-"` |
