# 0.3.4 — the handoff writes itself before the context is gone; the guard covers the tester

**Status:** design approved in chat by the operator 2026-09-08 · **Base:** main `2ca5772` (v0.3.3) · **Branch:** `feat/0.3.4`

## Why

0.3.3 closed the loop *after* a compaction: `PreCompact` stamps the ledger, `SessionStart(compact)` prints the last `## Handoff` block into the fresh context. What it could not do is make sure that block exists. The handoff is written by the session, by discipline, and the discipline fails exactly when it matters: a long turn fills the window and auto-compaction fires before anyone thought of the ledger. The hooks Claude Code offers do not fix this on their own — `PreCompact` runs after the decision to compact, its output never reaches the model, and it accepts no `prompt`/`agent` hook type — so the summary Claude Code writes is the only record, and it is not ours.

Claude Code does give the ingredients for something better. Every assistant message in the session transcript carries the request's token usage, a hook receives the transcript path on every event, a `PostToolUse` hook can put a line into the model's context, and a `Stop` hook can refuse to let a turn end. 0.3.4 combines them: **when the context passes a threshold (90 % by default), the guard tells the session to write its handoff now, and does not let the turn end until it has.** The handoff is still written by the session, with the whole context in view; the hook only makes sure it happens.

The rest of the release is guard hygiene that fits the same file — the tester gets the same containment as the coder, three classifier quirks from the 0.3.3 reviews get regression tests — and three one-line items from the backlog.

Order of work: **1 (auto-handoff) → 2 (guard: tester + quirks) → 3 (small items)**. Each package lands on its own; 1 is the release.

## 1. Auto-handoff: threshold nudge and stop gate

### 1a. Measuring the context

The guard learns the context fill from the transcript, not from Claude Code (no hook input carries it):

- Read the **tail** of `transcript_path` (last 256 KiB, `O_RDONLY | O_NOFOLLOW`, must be a regular file), split into lines, take the **last** line that parses as JSON with `message.usage`. Fill = `input_tokens + cache_read_input_tokens + cache_creation_input_tokens` of that record (each treated as 0 when absent). This is the size of the last request's prompt — what the next request will be, plus one turn.
- **Ceiling**, first source that yields a positive integer: the rendered `handoff.contextWindow` when non-zero → env `CLAUDE_CODE_AUTO_COMPACT_WINDOW` → `autoCompactWindow` in the user's Claude Code settings (`~/.claude/settings.json`, `$CLAUDE_CONFIG_DIR` honoured, same reading rules as `readClientEnv`: unreadable = skipped) → **200000**. Both env and setting accept the `500k` / `1m` forms Claude Code documents; the parser accepts a bare integer, `<n>k`, `<n>m`, case-insensitive, and rejects anything else.
- **Percent** = `floor(fill * 100 / ceiling)`. Threshold = rendered `handoff.threshold` (default **90**).

Anything unreadable or malformed — no transcript, no usage line, a ceiling that fails to parse — means *no measurement*, and no measurement means the hook is silent (exit 0, no output). The guard never blocks a turn on a guess.

### 1b. State and freshness

State lives in `<cwd>/.omelette/handoff-state.json` (0600, tmp + rename, `lstat` refuses a symlink; the directory itself passes the same `ledgerDir` check the other events use). One entry per `session_id`:

```json
{ "<session_id>": { "crossedAt": "<ISO>", "ledgers": { "ledger-0.3.4.md": 18342 }, "nudged": true, "blocked": false } }
```

- **Crossing**: the first measurement at or above the threshold with no entry for the session records `crossedAt` and the **current byte size of every `ledger-*.md`** in `.omelette/`. Entries older than 7 days are pruned on every write; the file is capped at 64 entries (oldest dropped).
- **Fresh handoff**: any ledger whose current size exceeds its recorded size *and* whose appended bytes (read from the recorded offset, at most 64 KiB) contain a line matching `^## Handoff\b`. A ledger created after the crossing counts with offset 0. Nothing else counts: a `Ruling:` line is not a handoff, and neither is the `## Compaction` stamp.
- **Reset**: `PreCompact` deletes the session's entry (the next window will cross again). A measurement below the threshold with an existing entry also deletes it (a compaction the guard did not see, or a session that trimmed itself).
- **Opt-in by ledger**: when `.omelette/` does not exist or holds no `ledger-*.md`, the hook measures nothing and says nothing — the ledger is the operator's signal that this session keeps a handoff. `doctor` says so (§1e).

### 1c. `PostToolUse`: the nudge

Fires on every tool (the snippet group has no matcher; a matcher here would only skip tools that also grow the context). Skipped outright when the event carries `agent_id` or `agent_type` (a sub-agent has no ledger of its own) or when `handoff.enabled` is false.

At or above the threshold, with an entry that is not yet `nudged` and no fresh handoff, the guard prints one JSON object and exits 0:

```json
{ "hookSpecificOutput": { "hookEventName": "PostToolUse",
  "additionalContext": "omelette-fleet: context at 91% of 200000 tokens (autoCompactWindow). Append a `## Handoff` block to .omelette/ledger-0.3.4.md now — where the work stands, open findings, agents in flight, next action — auto-compaction is close." } }
```

The ledger named is the most recently modified one; with several, the line says `one of the ledgers in .omelette/`. `nudged` is set. Below the threshold, or already nudged, or a fresh handoff exists: no output.

### 1d. `Stop`: the gate

Skipped when `stop_hook_active` is true (Claude Code is already continuing because of a stop hook), when the event carries `agent_id`/`agent_type`, or when `handoff.enabled` is false. Otherwise, with an entry for the session (the threshold was crossed), no fresh handoff, and `blocked` still false, the guard prints and exits 0:

```json
{ "decision": "block",
  "reason": "omelette-fleet: context at 91% of 200000 tokens and no `## Handoff` block has been appended to .omelette/ledger-0.3.4.md since the threshold was crossed. Append it now (state, open findings, agents in flight, next action), then stop." }
```

`blocked` is set: the gate holds a turn **once** per crossing. If the session stops again without a handoff, it stops — the guard reminds, it does not imprison. The measurement is re-taken on `Stop` (the session may have written the handoff since the nudge; a fresh block means no block).

### 1e. Config, render, snippet, doctor

- **Config**: a top-level `handoff` block in `fleet.config.json`, schema beside `AGENT_SETTINGS_SCHEMA`, validated the same way (invalid → warning + default): `enabled` (boolean, `true`), `threshold` (integer 50–99, `90`), `contextWindow` (integer ≥ 0, `0` = resolve at run time per §1a). `omelette-fleet set handoff.threshold=85`, `show` lists the block.
- **Render**: the guard is self-contained (it imports nothing from `core/`), so the values are substituted at `rules --hooks` time through a `{{handoff}}` placeholder that becomes a JSON literal, the way `{{marker}}` is filled today and `agents.tester.maxTurns` is rendered into the agent definition. Changing a value is `set … && rules --hooks`; the version marker gains nothing, so `doctor` cannot tell a stale threshold from a current one — the doctor line (below) prints the rendered value read back from the installed guard.
- **`HOOK_EVENTS`** becomes `['PreToolUse', 'PreCompact', 'SessionStart', 'PostToolUse', 'Stop']`; the snippet adds `"PostToolUse": [ { "hooks": [ … ] } ]` and `"Stop": [ { "hooks": [ … ] } ]`, no matcher. `MATCHED_ON` is unchanged (the two new events need none), `hookWiringAt` unions over five, an install still at three shows `hooks: … missing PostToolUse, Stop` and the next-step line says to re-run `rules --hooks` and paste the snippet.
- **`doctor`** prints one line per project when a guard is installed: `handoff: nudge at 90% of 200000 (default) · Stop gate on · ledgers: 1` — the ceiling's source in parentheses (`handoff.contextWindow` / `CLAUDE_CODE_AUTO_COMPACT_WINDOW` / `autoCompactWindow` / `default`), `ledgers: none (hook silent — start .omelette/ledger-<plan>.md)` when there is nothing to guard.

### 1f. What the session is told

The rules template and ORCHESTRATION gain a short paragraph under "Ledger and handoff": at the threshold the guard puts a reminder into context and holds the turn once; the block the session writes then is the one `SessionStart(compact)` prints after the compaction. The discipline stands — handoffs at every natural pause — the hook is the net under it. Manual `/compact` below the threshold gets no reminder (documented, with the PostCompact-copy idea left in the backlog).

## 2. Guard: the tester is contained too; three classifier quirks

- **2a.** `GUARDED_AGENT` becomes a set `{ omelette-coder, omelette-tester }`; the refusal names the agent that was caught. The tester runs the same Bash the coder does and was held back by its prompt alone. The tester definition template and the docs (rules, ORCHESTRATION, SECURITY) say both roles are guarded.
- **2b.** `git rebase --exec <cmd>` / `-x <cmd>`: the option takes a value, and today an **unquoted** `--abort` sitting in that value position (`git rebase --exec --abort main`) reads as the recovery form and passes, while git runs a rebase whose exec command is `--abort`. The rebase classifier skips option values the way `tagWrites` does (`--exec`, `-x`, `--onto`, `--strategy`, `-s`, `--strategy-option`, `-X`, `--gpg-sign`, `-S`, `--exec=` form included). Regression test on the exact command.
- **2c.** `git tag --sort --list`: `--sort` takes a value and swallows `--list`; the guard and git then agree (git rejects the sort key, nothing is written), so this is a test, not a fix — pin the behaviour, and `git tag --sort --list v1` (git would create `v1`) must be refused as it is today.
- **2d.** `$1` in the hook command: the settings snippet single-quotes the absolute guard path on POSIX; a path containing `$`, a space or a quote must survive `shellQuote` on both platforms. Test with such a path; fix the quoting if it does not.

## 3. Small items

- **3a. Spool header `model:` is never empty.** The adapter reports the model it actually asked for through `ctx.usedModel(id)` when it pinned one itself (Codex pins `catalog.ids[0]` when nothing is configured); the runtime's `finish()` spools `model:` as the explicit/configured model, else the adapter's report, else the literal `(vendor default)` (Grok and Gemini trust their CLI's default and do not learn its id). `results` and `<unit>_result` show the same string.
- **3b. CONFIG "Client timeouts"**: one sentence — Claude Code ≥ 2.1.263 passes `_meta.progressToken` on every `tools/call` and progress resets the idle watchdog (verified in the binary 2026-09-08), so the idle wall only bites on a client that does not.
- **3c. `readClientEnv` names an unreadable settings file.** Today a settings file that exists but fails to parse is skipped silently; `hookWiringAt` already reports `unreadable`. `readClientEnv` returns `unreadable: [paths]` beside its value and `doctor` prints `settings: <path> unreadable — env values in it were not consulted`, once per file, shared with the hook-wiring report.

## Non-goals

- No `PostCompact` copy of Claude Code's summary into the ledger (rides an undocumented transcript field, duplicates what `SessionStart` prints) — backlog.
- No blocking of a manual `/compact` — the operator's command wins.
- No `prompt`/`agent`-type hooks: `PreCompact`/`PostCompact`/`SessionStart` do not support them, and the guard stays a plain command hook with zero model calls.
- No `doctor --probe-sandbox`, `gemini_image` bare-path contract, per-unit contract dedup, Windows harness — 0.3.5 / separate.
- The guard remains containment for the coder and tester sub-agents, not a security boundary.

## Testing

Guard tests drive the script through stdin with a fake transcript JSONL and a fake settings file in a temp `HOME`/`CLAUDE_CONFIG_DIR`: nudge once at 90 % of the resolved ceiling and never below; ceiling precedence (config → env → setting → 200000, `500k`/`1m` forms, garbage → default); `agent_type`/`agent_id` → silent; `stop_hook_active` → silent; no ledger → silent; fresh `## Handoff` after the crossing → no nudge, no block; `Ruling:` line alone → still blocks; block once, then stops normally; `PreCompact` resets; fill dropping below the threshold resets; unreadable/oversized/symlinked transcript or state → silent exit 0; state file pruning and cap; output is exactly one JSON object. Rules: snippet has five groups, `HOOK_EVENTS` order, `{{handoff}}` rendered from config, `set handoff.threshold` validation bounds. Doctor: wiring union over five, `missing PostToolUse, Stop`, the handoff line and its ceiling source, unreadable-settings line. Guard classifier: 2b/2c/2d regressions. Unit: `model:` header for explicit, configured, adapter-pinned and vendor-default runs. Full suite pristine before each package commit.
